# Vencimientos PT

Quiero crear el primer MVP a partir de este Documento de Producto. Priorizá una versión simple, funcional y fácil de probar. Tomá las decisiones técnicas necesarias sin pedirme definiciones de arquitectura o programación. La aplicación debe reemplazar una planilla Excel de seguimiento de vencimientos de Precios de Transferencia. La pantalla principal debe mostrar indicadores, próximos vencimientos, obligaciones vencidas y una vista clara de prioridades. Debe existir una gestión de empresas, ejercicios fiscales y obligaciones, permitiendo asignar responsables, actualizar estados, registrar fechas de vencimiento y, opcionalmente, la fecha de presentación. Incorporá una vista calendario mensual y una tabla filtrable por cliente, responsable, estado, tipo de presentación y fecha. Aplicá un semáforo visual para resaltar la urgencia de los vencimientos y utilizá datos de ejemplo para que la aplicación pueda probarse desde el primer momento. Cuando falte una decisión de negocio relevante, preguntámela en lenguaje simple. Prepará una primera versión lista para validar y mejorar dentro de Lovable.
